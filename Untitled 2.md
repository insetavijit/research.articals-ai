## Content & Language Parameters

| Parameter               | Brief Description                                                                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Reading Grade Level** | Target 6th-11th grade level for general audience. News should be accessible to average readers (Flesch-Kincaid Grade Level 8-11).               |
| **Sentence Length**     | Most sentences should be 15-20 words maximum. Less than 25% of sentences should exceed 20 words. Vary length for rhythm.                        |
| **Paragraph Length**    | Keep paragraphs to 2-3 sentences maximum (ideally under 4 lines). Each paragraph should focus on one main idea.                                 |
| **Word Complexity**     | Use simple, common words. Avoid jargon and technical terminology unless essential. If specialized terms are needed, provide brief explanations. |
| **Active Voice Usage**  | Use active voice predominantly. Passive voice should be minimal as it makes content harder to understand and less engaging.                     |
| **Conversational Tone** | Write as if explaining to a friend. Natural, approachable language increases engagement and comprehension.                                      |
| **Transition Words**    | Use signal words (however, moreover, therefore, also, instead) to connect ideas smoothly and improve flow.                                      |
| **Avoiding Repetition** | Vary vocabulary and sentence starters. Don't begin 3+ consecutive sentences with the same word. Use synonyms appropriately.                     |
